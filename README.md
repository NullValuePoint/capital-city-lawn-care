# Capital City Lawn Care

A landing page for a fictional lawn care service in Lincoln, Nebraska. Portfolio project built with plain HTML, CSS, and JavaScript.

## Features

- Responsive layout with mobile navigation
- Interactive quote calculator (service type, lawn size, frequency)
- Pricing tiers, testimonial carousel, FAQ accordion
- Quote form with client-side validation
- Scroll-triggered animations

## Run locally

Open `index.html` in a browser, or serve the folder with any static server:

```sh
python3 -m http.server 8000
```
